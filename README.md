# Golden Vows

Create a beautiful Uzbek wedding invitation website with the following features:

Design:

Elegant beige and brown color palette with gold accents

Luxury feel similar to momento.uz

Floating rose petals animation throughout the site

Smooth scroll animations on all sections

Mobile-first responsive design

Beautiful typography using Cormorant Garamond font

Sections (single page, vertical scroll):

Intro screen - Full screen photo background with a glowing heart button that says "Yurakchani bosib taklifnomani oching" - clicking opens the invitation

Hero section - Large couple names "Jasur & Nilufar" in elegant serif font, wedding date "15 Avgust 2025", and a live countdown timer showing days, hours, minutes, seconds

Invitation text - "Aziz mehmonlar, sizni to'yimizga taklif etamiz" in elegant Uzbek language

Schedule (Kun dasturi) - Beautiful timeline showing: 19:00 Mehmonlar yig'ilishi, 19:30 Rasmiy qism, 20:00 Asosiy dastur, 22:00 Kechaning yakuni

Calendar - Show August 2025 calendar with wedding date highlighted in gold

Location (Manzil) - Venue name, address, embedded Google Map, buttons for Google Maps and Yandex Maps

Photo gallery - Masonry grid gallery with couple photos

RSVP form - Card with fields: Full name, Attendance (Ha kelaman / Kelolmayman dropdown), Number of guests, Comment. Submit button sends data to https://formspree.io/f/xpqekqwr

Closing - Arabic ayat "وَأَلَّفَ بَيْنَ قُلُوبِهِمْ" with translation "Va U ularning qalblarini birlashtirdi - Al-Anfol 63"

Animations:

Floating flower petals (🌸🌺) falling continuously

Fade-in animations on scroll for each section

Heartbeat animation on intro heart button

Smooth countdown timer updates every second

Music:

Background music autoplay on first click

Music toggle button (top right corner) with pause/play icon

Make it look premium, romantic and elegant - similar to high-end wedding invitation websites.
